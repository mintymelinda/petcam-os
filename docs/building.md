Use `sudo petcam-admin` only when you need to recover a lost web-manager password. It requires local shell or SSH access and an explicit `RESET` confirmation. The factory reset restores PetCam application settings and credentials to first-run defaults, removes camera profiles and PetCam-generated timelapse/motion data, and leaves OS, Wi-Fi/networking, SSH, TLS identity, updater trust, and installed software untouched.
